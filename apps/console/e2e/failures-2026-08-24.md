## A. Tasks toolbar `Create` became a dropdown — 10 failures

`ISS-2714: Ability to create + use task templates (#2170)` replaced the toolbar
Create button with `create-task-dropdown.tsx`: clicking it opens a menu offering
**From Scratch** / **From Template**. Tests click Create and immediately wait for
`getByRole('dialog')`.

| Test                       | Assertion that fails                           |
| -------------------------- | ---------------------------------------------- |
| `tasks.spec.ts:24`         | `expect(dialog).toBeVisible()`                 |
| `tasks.spec.ts:42`         | ditto                                          |
| `tasks.spec.ts:69`         | ditto                                          |
| `tasks.spec.ts:135`        | `dialog.getByText('Create a new Task')`        |
| `tasks.spec.ts:152`        | `expect(dialog).toBeVisible()`                 |
| `tasks.spec.ts:185`        | ditto                                          |
| `tasks.spec.ts:218`        | ditto                                          |
| `tasks.spec.ts:249`        | ditto                                          |
| `tasks.spec.ts:282`        | ditto                                          |
| `cross-cutting.spec.ts:74` | ditto ("Escape closes the create-task dialog") |

**Fix:** one shared helper in `e2e/utils/` —

```ts
export const openCreateTaskDialog = async (page: Page) => {
  await page
    .getByRole('main')
    .getByRole('button', { name: /^create$/i })
    .click()
  await page.getByRole('menuitem', { name: /From Scratch/i }).click()
  const dialog = page.getByRole('dialog')
  await expect(dialog).toBeVisible({ timeout: 10_000 })
  return dialog
}
```

Separate: `tasks.spec.ts:95` fails on `getByLabel(/^Card view$/)` — the
TableCardView toggle's accessible name changed. Not part of this cluster.
